Tentang Aplikasi

Proyek hackathon untuk keselamatan pasien berbasis teknologi

🎯

Visi

Setiap tahun, ribuan pasien mengalami efek samping serius akibat kombinasi obat yang tidak terdeteksi. Polypharmacy Collision Detector hadir sebagai lapis pertahanan kedua bagi apoteker dan dokter — memberikan peringatan instan sebelum resep diberikan kepada pasien.

✅

Fitur yang Tersedia

  • ✓ Deteksi 12+ pasangan interaksi obat berbahaya
  • ✓ 3 level risiko: Kritis, Sedang, Aman
  • ✓ Penjelasan klinis lengkap untuk setiap interaksi
  • ✓ Saran obat alternatif yang lebih aman
  • ✓ Risk Score Meter 0–100 (gauge visual)
  • ✓ Graf visualisasi interaksi antar obat
  • ✓ Mode Resep Scanner (parse teks bebas)
  • ✓ Autocomplete nama obat saat mengetik
  • ✓ Kamus obat lengkap dengan filter pencarian
  • ✓ Dashboard statistik riwayat (donut chart)
  • ✓ Export / Cetak laporan PDF
  • ✓ Sistem autentikasi (login & daftar)
  • ✓ Riwayat pemeriksaan tersimpan lokal
  • ✓ Salin hasil ke clipboard
  • ✓ Mode gelap & terang
  • ✓ Responsif di semua perangkat

⚠️ Perhatian Penting: Aplikasi ini adalah prototipe hackathon dan tidak dimaksudkan sebagai pengganti penilaian klinis profesional. Database interaksi bersifat demonstratif dan tidak komprehensif. Selalu konsultasikan dengan apoteker atau dokter berlisensi untuk keputusan klinis resmi.
